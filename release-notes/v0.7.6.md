# Avalon 0.7.6

发布日期：2026-11-24

## 新增

- 统一会话架构：桌面、飞书、QQ、定时任务的消息全部写入唯一的 `main` 会话，消息携带来源标记
- 对话页新增来源筛选（全部 / 桌面 / 飞书 / QQ / 定时任务），可按渠道查看统一时间线
- 定时任务通知支持选择推送渠道：桌面通知 / 飞书 / QQ，也可只写入会话不主动推送
- 工具结果落盘：超过 `artifact_threshold_bytes` 的大体积结果写入 artifacts 目录，上下文只保留预览；新增 `read_tool_result` 工具按字符偏移回读完整内容
- 上下文预算管理：按模型的 `context_window` / `max_output_tokens` 计算输入预算，达到 `compress_trigger_ratio` 时自动压缩
- 压缩结果支持事实、决策、待办等结构化字段；新增滚动摘要更新，合并新旧摘要
- 非主人工具白名单 `non_owner_allowlist`：群聊成员、陌生人默认无工具权限，可显式放行只读安全工具
- 模型配置新增上下文窗口与最大输出 token；未配置时回退到 `[session_memory]` 兜底值
- 流式渲染性能优化：Markdown 按块增量解析、消息/流式/UI 状态分片订阅、独立流式气泡组件，长回答更跟手

## 变更

- 渠道配置中的 `session_mode` 已废弃：所有来源统一写入 `main`，旧字段仅保留解析兼容
- `compress_threshold` 默认改为 `0`，压缩主要由预算比例触发；旧绝对值配置仍可解析
- 启动时自动迁移旧的按渠道 / 按聊天隔离的会话数据：合并进 `main`、按来源补齐 origin、去重，并清理不完整的工具链
- 一次 run 成功结束时整轮原子提交；中断或取消的轮次不再留下半条 assistant/tool 轨迹
- 移除遗留的 `llm_compress` IPC 命令（压缩由 engine / session 内部完成）
- 对话页在飞书 / QQ / 定时任务筛选下隐藏输入区，改为只读提示，避免误以为能在渠道时间线里发消息

## 修复

- 发送消息后列表不跟随滚动：改用用户滚动行为维护的 sticky 状态，不再在内容追加后实时测距
- 「加载更早」提示条常驻：会话切换、无更早块、内容不足一屏时正确复位
- 空会话收到后台渠道消息时流式输出不可见：列表空态改为由 store 的存在性驱动，流式气泡可正常挂载
- 后台轮次提交的消息保留来源标记，来源筛选与徽章不再依赖后端回填

## 升级说明

- 直接覆盖安装即可
- 首次启动会迁移旧会话数据，数据量大时可能稍慢；迁移结果会写入启动日志
- 旧配置中的 `session_mode` 会被忽略；如需控制压缩时机，建议使用 `compress_trigger_ratio` / `context_window` 等新字段
- 工具结果落盘会占用数据目录空间，长期使用可按需清理 artifacts
- 自定义过 `Avalon-config.toml` 的用户无需补齐新字段，省略时使用默认值
