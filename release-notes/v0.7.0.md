# Avalon 0.7.0

发布日期：2026-10-31

## 新增

- 文件存储模块：统一管理聊天与工具产生的文件，文件根目录可在配置中调整
- 视觉输入：聊天中可直接上传图片交给视觉模型理解，新增视觉设置页
- 图片查看工具与视觉服务，支持结合历史观察记录分析图片
- 本地 OCR 工具：基于 ONNX 的离线文字识别，支持方向分类，模型随包提供
- 图片近重复检测与复用，避免同一张图重复识别和上传

## 变更

- 文件根目录默认路径调整，旧数据目录结构保持兼容
- 配置模板补充视觉与 OCR 相关配置

## 发布

- Windows x64 NSIS 安装包：`Avalon_0.7.0_x64-setup.exe`
