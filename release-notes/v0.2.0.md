# Avalon 0.2.0

发布日期：2026-08-23

首个 Tauri 桌面版正式安装包。此版本把应用从早期原型整理成可安装、可日常使用的桌面程序。

## 新增

- 完整聊天界面：流式输出、Markdown 渲染、生成中断、模型切换
- 会话管理：多会话切换、归档、重命名、删除，历史记录渐进式加载
- ReAct 智能体引擎：工具调用过程可视化，上下文用量实时展示
- 记忆系统：本地嵌入模型（bge-small-zh）、向量检索、记忆索引重建
- 定时任务：按计划自动调度会话执行
- 多模型配置与完整设置页，TOML 配置文件与配置模板
- 关于页与统一 UI 组件库，整体界面重构

## 发布

- Windows x64 NSIS 安装包：`Avalon_0.2.0_x64-setup.exe`
- 附 LICENSE 与完整 README
