# Avalon 0.7.2

发布日期：待定（当前 `main` 已提交 0.7.0 之后的渠道与通讯录改动，版本号已更新为 0.7.2）

## 新增

- QQ 渠道（官方机器人）：单聊与群聊接入，单聊流式输出、群聊非流式输出
- 渠道通讯录：记录对话过的用户 id、昵称与画像
  - 主人区单独维护：只存渠道主人 id 与昵称，由首次私聊自动记录
  - 设置页通讯录顶部可查看并更正主人
- 飞书收到图片后先发送确认询问文本，等待用户说明意图再处理
- OCR 方向分类器：倒置文本先转正再识别

## 变更

- 飞书 / QQ 的主人 id 从渠道设置页迁入通讯录，渠道设置页不再出现 `owner_open_id`
- 旧配置中的 `owner_open_id` 在首次启动时自动迁入通讯录，之后不再读写该配置项
- 主人画像统一归灵魂模块维护，通讯录不存主人画像
- `feishu_notify_owner` / `qq_notify_owner` 改为从通讯录读取收件人
- 渠道工具发送失败时附带渠道状态（是否在线、本分钟剩余额度、上次成功时间）

## 修复

- 清理主人迁移后遗留的未使用代码与警告
- QQ 事件解析补充发送者昵称

## 升级说明

- 直接覆盖安装即可，旧配置会在启动时自动迁移
- 若之前把主人记在了通讯录的普通用户区，主人区仍会正常生成；旧用户条目不会自动删除，可在通讯录页手工清理

## 发布

- Windows x64 NSIS 安装包：`Avalon_0.7.2_x64-setup.exe`（需在 0.7.2 提交后重新打包）
