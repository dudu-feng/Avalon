# user_profile.md — 用户画像

## 使用说明
- 本文件用于存储用户画像，属于智能体对用户的了解和认识。
 - 本文件的更新由智能体在梦境机制下对已有对话和记忆进行分析之后更新
- 所有信息均基于用户**自愿或间接透露**的内容。如果用户从未提及，对应字段保持为空或默认值。
- 优先级：用户明确告知 > 智能体从对话中推断（标注“推测”字段）> 默认中性值。

## 更新规则（内嵌于智能体行为）
**如何记录推断**：若信息来自推断，用 `[推测]` 标记，例如 `兴趣话题：[推测] 可能喜欢咖啡，因为多次提到咖啡馆环境`。
**冲突处理**：若新信息与旧记录冲突，以**最近一次且用户明确表述**为准，并在字段旁注明 `[已更新：旧值xxx -> 新值yyy，日期]`。
**隐私保护**：绝不记录真实的姓名、地址、账号等可识别信息。如果用户主动说出，智能体应在内部标记 `[未存储]` 并提醒用户不要分享敏感信息。
**更新格式**：参考现有格式
    """
      ## 字段名
      - 字段内容
    """

## 用户对智能体的偏好（元偏好）
- **称呼我的方式**：默认“你”或自定义昵称
- **希望我扮演的角色**：默认对话伙伴 / 导师 / 树洞 / 合作 brainstorm 伙伴
- **纠错容忍度**：默认欢迎纠正 / 仅纠正事实错误 / 不希望被纠正风格问题
- **隐私边界**：默认我可以在本对话中引用之前说过的话 / 不要主动提起某些话题（如健康、财务状况）

## 沟通风格与交互偏好

- **智能体主动程度**：默认中等（主动追问1-2次） / 低（完全由用户驱动） / 高（主动拓展话题）
- **幽默容忍度**：默认中等 / 喜欢幽默 / 不喜欢幽默（希望保持严肃）
- **反馈节奏**：默认正常 / 希望我多问“我这样解释清楚吗？” / 希望我直接给结论
- **对不确定性的态度**：默认接受“我不知道” / 希望我尽量猜测 / 必须确认事实
