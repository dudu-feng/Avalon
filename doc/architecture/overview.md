# 整体架构概览

## 1. 设计理念

Avalon 是一款个人 AI 智能体，采用 **双层 ReAct 循环** 架构：

- **对话层 (Chat Layer)**：接收用户输入，决策是直接回复还是需要执行操作
- **动作层 (Action Layer)**：执行具体的多步骤任务，支持工具调用、子分析、逐步推进

配合 **永恒会话 (Eternal Session)** 机制，通过压缩、渐进式总结、向量检索实现长期记忆。

## 3. 模块职责一览

| 模块 | 目录 | 职责 |
|------|------|------|
| **配置中心** | `config/` | 加载 .env，提供全局配置单例 |
| **LLM 交互** | `llm/` | 封装三种 LLM 调用：对话、动作执行、会话压缩 |
| **ReAct 循环** | `loop/react_loop.py` | 双层循环引擎，协调 LLM 与工具 |
| **提示词组装** | `loop/prompt_assemble.py` | 加载 Markdown 提示词文件，组装系统提示 |
| **会话管理** | `loop/session_manage.py` | 会话 CRUD、压缩、渐进式总结、上下文裁剪 |
| **Embedding 服务** | `loop/embedding_service.py` | 本地 SentenceTransformer 模型，文本向量化 |
| **向量存储** | `loop/zvec_store.py` | ZVec 向量数据库，支持向量/全文/混合检索 |
| **基础工具** | `tool/base_tool.py` | 文件读写删、Shell 命令、目录浏览 |
| **记忆检索工具** | `tool/session_memory_tool.py` | 历史会话语义/关键词/混合检索 |

## 4. 技术栈

| 类别 | 技术 | 用途 |
|------|------|------|
| LLM 框架 | LangChain (langchain-openai) | LLM 调用、消息构造、工具装饰器 |
| LLM 接口 | OpenAI 兼容 API | 对话/动作/压缩模型调用 |
| 向量数据库 | ZVec | 会话记忆存储与检索 |
| Embedding | sentence-transformers (bge-small-zh-v1.5) | 本地文本向量化 |
| 配置管理 | python-dotenv | .env 文件加载 |
| 数据格式 | JSON | 会话存储、LLM 输出解析 |

## 5. 核心设计模式

### 5.1 单例模式
- `EnvConfig` — 全局唯一配置实例
- `EmbeddingService` — 全局唯一 Embedding 模型实例（懒加载）
- `ZvecStore` — 全局唯一向量数据库连接

### 5.2 双层 ReAct 循环
```
用户输入
  │
  ▼
┌─ 对话层循环 ─────────────────────────┐
│  llm_chat() → 解析 JSON             │
│  ├─ next=stop    → 返回回复          │
│  ├─ next=action  → 进入动作层 ──┐    │
│  └─ 无法解析     → 纯文本回复    │    │
└────────────────────────────────┼────┘
                                 │
┌─ 动作层循环 ←──────────────────┘    │
│  llm_action() → 解析 JSON           │
│  ├─ next=tool_call     → 执行工具   │
│  ├─ next=sub_analysis  → 继续分析   │
│  ├─ next=finished      → 完成返回   │
│  └─ 其他               → 错误终止   │
└─────────────────────────────────────┘
```

### 5.3 永恒会话机制
```
会话数据膨胀
  │
  ▼
达到 token 阈值 → session_compress()
  │                ├─ LLM 压缩为摘要+关键词
  │                ├─ 原始数据归档到 raw/
  │                └─ 摘要写入 ZVec 向量库
  ▼
压缩块超过 max_chunks → _progressive_summarize()
  │                       ├─ 旧块合并为超级摘要
  │                       ├─ super_compressed 永远只保留 1 个
  │                       └─ ZVec 同步更新
  ▼
系统提示加载上下文 → get_session_context_for_prompt()
  │                      ├─ super_compressed: 始终包含
  │                      ├─ compressed: 最近 N 个
  │                      └─ 旧块: 通过 search_session_memory 按需检索
```
